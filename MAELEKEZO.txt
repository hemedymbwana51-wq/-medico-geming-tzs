MEDICO GAMING TZ: kuunganisha seva (Supabase, bure)

1. Fungua supabase.com, jisajili, bonyeza New project (chagua region iliyo karibu, mfano Frankfurt au Cape Town).
2. Authentication > Providers > Email: zima "Confirm email" (ili watu wasihitaji barua pepe).
3. SQL Editor > New query: bandika setup.sql yote, bonyeza Run.
4. Project Settings > API: nakili "Project URL" na "anon public key".
5. Fungua index.html, badilisha mwanzoni mwa script:
   SB_URL="PASTE_SUPABASE_URL"  ->  weka Project URL
   SB_KEY="PASTE_ANON_KEY"      ->  weka anon key
6. Pakia faili zote kwenye GitHub (medicogamingtz51.github.io).
7. Fungua tovuti, bonyeza Ingia > Jisajili kwa namba 0771641624 (wewe kwanza, kabla ya mtu mwingine).
8. Supabase SQL Editor: endesha admin.sql. Sasa akaunti hiyo ni admin.
9. Fungua tovuti/#admin, ongeza games zako na weka link za download.

Mteja: anajisajili kwa namba, anabonyeza Fungua kwenye game ya kulipia, anatuma pesa kwa 0771641624 (Abduli), anapakia screenshot.
